\# Laboratorio: Administración y Copias de Respaldo Lógicas



Bienvenidos a este entorno de simulación. Como arquitectos de datos de EcoRutas Logistics, nos enfrentamos al reto de asegurar la telemetría vital de nuestra flota de camiones.



\### ¿Qué haremos?

1\. Desplegaremos un servidor MongoDB aislado usando Docker y lo conectaremos a un volumen en nuestro servidor Linux.

2\. Inyectaremos 10,000 registros de telemetría simulados.

3\. Aprenderemos a crear una copia de respaldo lógica usando mongodump.

4\. Simularemos un error humano crítico que destruirá la base de datos de producción.

5\. Restauraremos la operación del negocio usando mongorestore.



Cuando estés listo para proteger los datos de la empresa, avanza al primer paso.
