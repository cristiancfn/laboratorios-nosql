# Laboratorio: Alta Disponibilidad con MongoDB



Bienvenidos. En este entorno efímero construiremos un clúster de bases de datos no relacionales para demostrar la tolerancia a fallos mediante un \*\*Replica Set\*\*.



### ¿Qué haremos?

1\. Desplegaremos tres instancias independientes de MongoDB usando Docker.

2\. Configuraremos las instancias para que actúen como un único clúster.

3\. Simularemos la caída del servidor principal para observar el proceso de elección automática.



Cuando estés listo, avanza al primer paso.
