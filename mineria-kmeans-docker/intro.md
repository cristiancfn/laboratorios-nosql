# Bienvenido a la simulación interactiva de Minería de Datos

Como Arquitecto de Datos moderno, debes saber cómo desplegar la infraestructura necesaria para procesar tus modelos analíticos de manera aislada y eficiente.

En este laboratorio, simularemos un proceso de Data Mining.

### Objetivo
Aprenderás a desplegar "Infraestructura como Código" utilizando **Docker Compose**. Levantaremos un contenedor aislado con las librerías necesarias para ejecutar un algoritmo de Clustering (**K-Means**) sobre un set de datos.
