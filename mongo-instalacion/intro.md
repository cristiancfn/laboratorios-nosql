# Instalación y Seguridad en MongoDB

En este escenario aprenderás a realizar una instalación nativa (bare-metal) de MongoDB en un servidor Ubuntu.

Aprenderemos a:
1. Instalar MongoDB usando el gestor de paquetes `APT`.
2. Modificar el archivo `mongod.conf` para permitir conexiones desde cualquier IP.
3. Usar `mongosh` para crear un usuario administrador.
4. Habilitar la seguridad y reiniciar el servicio usando `systemd`.

¡Comencemos!
