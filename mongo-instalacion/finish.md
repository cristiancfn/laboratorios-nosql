# ¡Felicidades!

Has completado con éxito la instalación nativa de MongoDB. Durante este escenario lograste:
* Instalar `mongodb-org` de forma directa en Ubuntu.
* Exponer el servicio modificando el `bindIp`.
* Utilizar `mongosh` para administrar la base de datos.
* Proteger tu instancia habilitando `security.authorization`.
