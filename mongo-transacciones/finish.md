# ¡Laboratorio Completado!

Como arquitecto de datos, hoy has comprobado tres principios fundamentales:

1\. **Rendimiento Masivo:** MongoDB puede insertar y guardar miles de registros por segundo gracias a su arquitectura por defecto (Auto-commit sin bloqueos).

2\. **Observabilidad:** Un administrador de base de datos debe usar el Database Profiler para cazar COLLSCANs asesinos de RAM y resolverlos con índices.

3\. **Resiliencia Lógica:** Gracias a WiredTiger y MVCC, MongoDB soporta Transacciones ACID multi-documento, protegiendo la información mediante Rollbacks automáticos cuando el software falla.
